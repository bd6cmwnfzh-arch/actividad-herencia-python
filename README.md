
# Actividad formativa 3: Herencia en Python

## Descripción
Este proyecto demuestra el uso de la herencia en la programación orientada a objetos utilizando Python.

## Objetivo
Crear clases derivadas que reutilicen atributos y métodos de una clase base.

## Clases utilizadas

- Empleado: clase base que contiene el nombre, sueldo y método para mostrar información.
- Gerente: clase derivada que hereda de Empleado y agrega el departamento y el método dirigir_equipo().
- Desarrollador: clase derivada que hereda de Empleado y agrega el lenguaje de programación y el método programar().

## Conceptos aplicados

- Herencia.
- Reutilización de código.
- Sobrescritura de métodos.
- Creación de objetos.
- Programación orientada a objetos.

## Lenguaje
Python 3.
